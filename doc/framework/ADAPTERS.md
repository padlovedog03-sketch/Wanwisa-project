## ข — ผู้ช่วยใดก็ได้ที่อ่าน `AGENTS.md` + git (ไม่มี C1)

**ไฟล์ของตัวเชื่อมนี้:** `AGENTS.md` · `.agents/skills/` · `.githooks/pre-commit` · `.githooks/commit-msg` (คอมมิต fix ต้องมีเทสต์) · `ci-examples/`
เปิดด่านก่อนคอมมิตครั้งเดียวต่อโคลน: `git config core.hooksPath .githooks`

| ความสามารถ | มี | ทางถอยที่ใช้ | สิ่งที่อ่อนลง |
|---|---|---|---|
| C1 การขัดจังหวะ | **ไม่มี** | ย้ายการตรวจไปที่ตอนคอมมิต (`.githooks/pre-commit`: ทะเบียนอนุมัติ, บันทึกแผล, ความจำ, ความเป็นกลาง) และที่ CI บนสาขาที่ป้องกัน | **คำสั่งทิ้งงานไม่มีอะไรกันเลย** · การเรียกช่างก่อนสเปกอนุมัติไม่มีอะไรกัน · `--no-verify` ข้ามด่านคอมมิตได้ เหลือ CI ด่านเดียว |
| C2 การมอบหมาย | แล้วแต่เครื่องมือ | ทำตามลำดับในผู้ช่วยตัวเดียว ส่งต่องานผ่านไฟล์ใน `doc/` | **ผู้ตรวจไม่เป็นอิสระจากผู้ทำ** ถ้าเป็นตัวเดียวกัน — ต้องประกาศในรายงาน QA |
| C3 คำสั่งที่คงอยู่ | มี — `AGENTS.md` มาตรฐานเปิด | — | บทบาทใน `.claude/agents/` อ่านไม่ได้ (ยังไม่มีมาตรฐานเปิดสำหรับนิยามผู้ช่วยย่อย) ใช้ชื่อบทบาทใน `AGENTS.md` §5 แทน |
| C4 ลงมือ+สังเกต | ต้องมี | ไม่มีทางถอย | เครื่องมือที่รันแล้วอ่านผลไม่ได้ ใช้กับเฟรมเวิร์กนี้ไม่ได้ |
| C5 การรู้จบ | ไม่มี | ผู้ช่วยประกาศจบเอง | ไม่มีรายงานงานเบื้องหลังที่ค้าง |
| R37 เครื่องวัดเวลาของผู้ช่วย | unsupported — ไม่มีตัวอ่านบันทึก | `scripts/agent_time.py` พิมพ์ `unsupported` แทนการพิมพ์ศูนย์ · เพิ่มได้โดยเขียนตัวอ่านตามสัญญาใน docstring ของสคริปต์ แล้วประกาศแถวนี้ใหม่ | ไม่มีตัวเลขเวลาของผู้ช่วยเลย ทั้งก่อนและหลังการเปลี่ยนแปลง |

**สถานะการพิสูจน์:** ด่านก่อนคอมมิตพิสูจน์แล้วด้วย `tests/framework/test_pre_commit.py` (ล้มจริงเมื่อฝังความผิด)
