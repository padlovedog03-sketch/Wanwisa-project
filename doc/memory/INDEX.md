# ความจำของโปรเจกต์ — สารบัญ

อ่านไฟล์นี้ทุกครั้งที่เริ่มงาน หนึ่งบรรทัดต่อหนึ่งเรื่องที่ยังมีผล รายละเอียดอยู่ในไฟล์ที่ลิงก์ไว้
กฎการเขียน: `doc/memory/README.md` · ตรวจด้วย `python3 scripts/memory_lint.py`

- [ความจำอยู่ในคลังโค้ด](memory-lives-in-the-repo.md) — ไม่อยู่ในโฟลเดอร์ส่วนตัวของเครื่องมือใด
- [เทสต์แดงของโปรเจกต์ เป็นงานของรอบฝั่งโปรเจกต์](project-reds-belong-to-project-session.md) — รอบในคลังเฟรมเวิร์กแก้แค่แม่แบบ ไม่แก้โปรเจกต์ปลายทาง
- [คลังนี้คืองานปรับปรุงเฟรมเวิร์ก](this-repo-improves-the-framework.md) — ไม่ใช่งานจริงของโปรเจกต์ใด ใช้โปรเจกต์ปลายทางแค่เป็นหลักฐานและที่ทดลอง
- [ส่งงานแก้เป็นใบสั่งใหม่](rework-goes-in-a-fresh-brief.md) — งานที่ QA ตีกลับต้องขึ้นต้นใบสั่งใหม่ด้วย REWORK: ไม่ใช่ส่งต่อท้ายข้อความ ไม่งั้นตัววัดนับไม่เห็น
- [ประตูแบบประหยัด และ QA ตามความเสี่ยง](lean-gates-risk-based-qa.md) — ไม่มีขั้นพี่ดูก่อน QA · ด่าน/เครื่องวัดใช้ QA เต็ม · งานข้อความใช้ผู้ตรวจเดียว
- [ทุกเกณฑ์รับงานต้องมีกรณีโจมตี](hostile-inputs-in-every-ac.md) — AC มีข้อห้ามล่ม/รั่ว · ช่างโจมตีตัวเองก่อนส่ง · ba-sa พิสูจน์ข้อสันนิษฐาน · ไฟล์หนึ่งมีเจ้าของเดียว
- [ใช้งานง่ายสำคัญกว่าเข้มงวด](ease-of-use-over-strictness.md) — ด่านดักคำสั่งกันพลาด ไม่ไล่ทุกทาง · ไม่มีลายเซ็นดิจิทัลจนกว่าจะมอบอำนาจถึง main/prod
